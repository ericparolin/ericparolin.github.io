# ericparolin.github.io

Personal academic website of Eric Parolin, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and hosted on GitHub Pages at https://ericparolin.github.io.

- Site settings and sidebar: `_config.yml`
- Top menu: `_data/navigation.yml`
- Pages: `_pages/` (`about.md` is the home page, plus `research.md` and `teaching.md`)
- PDFs (CV, papers): `files/`, served at `https://ericparolin.github.io/files/<name>.pdf`
- Profile photo: `images/profile.jpg`
